### 📱 5일 차: 모바일 앱 전환 및 극한의 트러블슈팅

**1. 📦 Capacitor 연동 (웹 코드를 모바일 앱으로)**

- **어떤 걸:** 웹사이트용으로 만든 코드를 스마트폰에 설치할 수 있는 안드로이드 앱 형태로 패키징했습니다.
    
- **어떻게:** `@capacitor/core`와 `cli`를 설치하고 안드로이드 플랫폼을 추가(`npx cap add android`)하여, 기존 React 코드를 1%도 수정하지 않고 그대로 껍데기(웹뷰) 안에 밀어 넣었습니다. (`npm run build` ➡️ `npx cap sync`)
    

**2. 🚧 지옥의 WSL ↔ Windows 환경 충돌 해결**

- **어떤 걸:** 리눅스(WSL)에서 작업한 코드를 윈도우의 안드로이드 스튜디오에서 읽어올 때 발생하는 고질적인 권한 및 경로 에러를 돌파했습니다.
    
- **어떻게:** `chmod` 권한 부여 시도 후, 가장 확실한 방법인 "프로젝트 전체 폴더를 윈도우 환경(바탕화면)으로 통째로 이사"하는 결단을 내려 npm 명령어(`package.json` 인식)와 그래들(Gradle) 동기화 오류를 한 방에 해결했습니다.
    

**3. ⬛ '까만 화면(Blank Screen)'의 원인 규명 및 격파**

- **어떤 걸:** 앱은 켜졌으나 화면이 까맣게 나오는 모바일 앱 특유의 렌더링 버그를 잡아냈습니다.
    
- **어떻게:** 크롬 검사기(`chrome://inspect`) 로그를 통해 앱이 에러로 죽은 것이 아님을 확인했습니다. 원인은 "모바일 웹뷰의 기본 배경색이 까만색(투명)인데, 로그인 컴포넌트에 하얀 배경을 칠하지 않아서 어둠 속에 묻혀있던 것"이었음을 밝혀내고, `App.jsx`와 `index.css`에 `bg-white` 캔버스를 강제로 깔아주어 화면을 마침내 띄워냈습니다!
    

**4. 📐 모바일 반응형(Responsive) 설계 돌입**

- **어떤 걸:** PC의 넓은 모니터에 맞춰진 3단 가로 배열을 모바일의 좁은 세로 화면에 맞게 뜯어고치기 시작했습니다.
    
- **어떻게:** Tailwind CSS의 모바일 퍼스트 원칙을 적용하여 기본적으로 블록들이 위아래로 쌓이게(`flex-col`) 만들고, 화면이 넓어질 때만 가로(`md:flex-row`)로 퍼지도록 `App.jsx`와 `CalendarView.jsx`의 메인 레이아웃 뼈대를 방금 수정했습니다.
