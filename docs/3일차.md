오늘 가계부 프로젝트에서 대대적으로 개편하고 추가한 핵심 내용들입니다!

---

### 1. UI/UX 및 레이아웃 전면 개편

- **3단 가로 레이아웃 적용**: 기존 2분할 화면에서 **사이드바(15%) | 달력(60%) | 상세 내역(25%)** 구조로 변경하여 훨씬 넓고 시원한 공간감을 확보했습니다.
    
- **컬러 시스템 통일**: 수입은 빨간색, 지출은 파란색으로 모든 UI(텍스트, 버튼, 그래프)를 통일해 시각적인 직관성을 높였습니다.
    

### 2. 컴포넌트 분리 및 구조 최적화 (리팩토링)

유지보수를 위해 하나로 뭉쳐있던 `App.jsx`를 역할별로 완벽하게 쪼갰습니다.

- **`App.jsx`**: 전체 상태 관리 및 화면 조립 (본부 역할)
    
- **`Sidebar.jsx`**: 좌측 메뉴바 (화면 전환 제어)
    
- **`CalendarView.jsx`**: 메인 달력과 우측 날짜별 상세 내역 렌더링
    
- **`Dashboard.jsx`**: 자산 리포트 요약 카드 및 연간 막대그래프
    
- **`TransactionModal.jsx`**: 내역 추가/수정/삭제 팝업창
    
- **`SettingsView.jsx`**: 앱 환경 설정 (다크 모드 제어)
    

### 3. 달력(Calendar) 세부 기능 고도화

- **스마트한 타일 렌더링**: 평소에는 날짜별 수입/지출 총액만 보여주고, 클릭하면 반투명한 서리유리(Frosted Glass) 효과와 함께 `+`, `-` 버튼이 나타나도록 UX를 개선했습니다.
    
- **레이아웃 버그 해결**: 달력 칸 높이를 140px로 고정하고, `react-calendar` 특유의 클릭 파란색 잔상을 완벽히 제거했습니다.
    
- **Today 버튼 연동**: 'Today' 버튼을 누르면 달력 화면이 현재 달로 즉시 이동합니다.
    

### 4. 상세 내역 관리 및 통계 (대시보드)

- **상세 내역 업그레이드**: 이제 단순히 카테고리만 고르는 게 아니라 "스타벅스 커피"처럼 **내용을 직접 입력**할 수 있습니다.
    
- **수정 및 삭제(CRUD) 구현**: 우측 상세 내역을 클릭하면 수정 모달이 열리며, 내용을 고치거나 아예 삭제할 수 있습니다.
    
- **대시보드 스마트 피드백**: 이번 달과 지난달의 데이터를 비교해 _"지난달보다 00원 더 썼어요 💸"_ 같은 피드백을 제공합니다. 연간 막대그래프도 Tailwind CSS만으로 깔끔하게 구현했습니다.
    

### 5. 다크 모드 (Dark Theme) 완벽 대응

- **Tailwind CSS v4 호환**: 최신 `@custom-variant dark` 문법을 사용해 다크 모드 토글 시스템을 구축했습니다.
    
- **설정 유지**: `localStorage`를 활용해 브라우저를 껐다 켜도 사용자가 선택한 테마가 유지됩니다.
    
- **라이브러리 강제 테마 적용**: `react-calendar` 내부의 하얀 배경, 테두리, 글자색 등을 `App.css`에서 강제로 다크 톤으로 덮어씌워 이질감 없는 다크 테마를 완성했습니다.
