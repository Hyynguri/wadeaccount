## 📝 가계부 프로젝트 개발 일지 (1일 차)

### **1. 개발 환경 세팅 (WSL & React)**

- **환경:** Windows Subsystem for Linux (WSL)을 활용하여 리눅스 환경에서 개발을 시작했습니다.
    
- **에디터 연동:** 리눅스 내부에 무겁게 에디터를 깔지 않고, 윈도우에 설치된 VS Code를 WSL과 연동하여 쾌적한 환경을 구축했습니다.
    
- **프로젝트 생성:** 속도가 빠른 `Vite`를 빌드 도구로 사용하여 React 기반의 웹 프로젝트를 생성했습니다.
    

### **2. 핵심 레이아웃 뼈대 구축 (3분할)**

- **구조 설계:** 화면을 크게 좌측(메뉴 20%), 우측 상단(달력 60%), 우측 하단(상세 내역 40%)으로 나뉘는 3분할 구조로 만들었습니다.
    
- **스타일링:** 디자인 코드를 직접 짜지 않고 직관적인 `Tailwind CSS`를 도입했습니다. 메인 영역에 `flex-col` 속성을 주어 달력과 상세 내역이 세로로 깔끔하게 쌓이도록 구현했습니다.
    

### **3. 가계부 전용 달력 커스텀**

- **라이브러리 적용:** 수학적 계산의 피로도를 줄이기 위해 검증된 `react-calendar` 라이브러리를 도입했습니다.
    
- **바둑판 UI (Grid):** 기본적으로 크기가 고정되어 있던 달력을 화면(할당된 레이아웃)에 100% 꽉 채우도록 변경했습니다. 특히 첫째 주가 화면을 다 차지하던 문제를 `CSS Grid`를 적용해 완벽한 바둑판 형태로 등분하여 해결했습니다.
    
- **사용자 편의성:** 가계부에 불필요한 10년 단위 이동 버튼(`<<`, `>>`)을 깔끔하게 제거하고 , 언제든 현재 월로 돌아올 수 있는 '오늘' 버튼을 추가했습니다.
    

### **4. 데이터 입력 모달(Modal) 창 구현**

- **이벤트 연결:** 달력의 특정 날짜 칸이나 우측 상단의 '+ 내역 추가' 버튼을 클릭했을 때 화면 중앙에 팝업이 뜨도록 구현했습니다.
    
- **수입/지출 및 카테고리:** '수입'과 '지출'을 토글로 선택할 수 있으며, 선택에 따라 하단의 '카테고리' 목록(식비, 월급 등)이 동적으로 바뀌도록 만들었습니다.
    
- **금액 포맷팅:** 금액 입력 창에 숫자를 적으면 자동으로 1,000 단위마다 콤마(,)가 찍히도록 UX를 개선했습니다.
    

### **5. 오늘의 트러블슈팅 (Troubleshooting)**

- **Tailwind 버전 충돌:** Tailwind CSS가 최신 버전(v4)으로 설치되면서 발생한 빌드 에러를, 이전 방식의 설정 파일을 지우고 `@tailwindcss/vite` 전용 플러그인을 설치하는 최신 방식으로 변경하여 해결했습니다.
    
- **화면 크래시(White Screen):** 모달 창을 띄울 때 화면이 하얗게 멈추는 에러가 발생했으나 , 닫기 버튼용 `<X />` 아이콘의 `import` 구문 누락을 찾아내어 성공적으로 디버깅했습니다.
