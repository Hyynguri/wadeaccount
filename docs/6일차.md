오늘 하루 동안 진행된 가계부 앱의 **모바일 UI/UX 고도화 작업**을 한눈에 보기 쉽게 정리해 드릴게요!

단순한 웹 화면을 넘어, 실제 스토어에 출시된 **'네이티브 핀테크 앱' 수준의 부드러운 조작감과 디자인**을 완성한 엄청난 하루였습니다. 🚀

---

### 📱 오늘 달성한 핵심 업데이트 요약

**1. 쫀득한 바텀 시트(Bottom Sheet) 제스처 구현**

- **실시간 손가락 추적:** 이력 패널을 위아래로 스와이프할 때 화면이 딱딱하게 끊기지 않고, 손가락 움직임(픽셀)에 맞춰 달력과 패널의 크기가 고무줄처럼 실시간으로 연동되도록 구현했습니다.
    
- **황금 비율(53%) 세팅:** 달력을 위로 올렸을 때 달력이 납작하게 찌그러지지 않도록, 화면의 53% 높이를 고정적으로 확보하여 시각적인 안정감을 주었습니다.
    
- **내부 스크롤 보호:** 이력 패널이 열린 상태에서 내역을 위아래로 스크롤할 때, 창이 실수로 닫히지 않도록 제스처 충돌을 방지했습니다.
    

**2. 네이티브 감성의 '무한 슬라이드(Carousel)' 장착**

- **깜빡임 없는 좌우 스와이프:** 이전/현재/다음 화면을 미리 렌더링하여 가로로 길게 배치(`w-[300%]`)한 뒤, 좌우로 밀 때 기차가 이동하듯 물리적으로 딸려 오게 만들어 새로고침되는 느낌(깜빡임)을 완벽히 없앴습니다.
    
- **달력 스와이프 (월 변경):** 달력을 좌우로 밀면 이전 달 / 다음 달로 스무스하게 넘어갑니다. (기본 `< >` 버튼 삭제)
    
- **이력창 스와이프 (일 변경):** 아래 이력 리스트 창을 좌우로 밀면, 어제 / 내일 날짜로 슉슉 이동합니다.
    

**3. 달력 디자인 및 렌더링 최적화**

- **3x4 월 선택창 뷰 복구:** 상단의 '5월' 글자를 눌렀을 때 나오는 연도별 보기(Year View)가 세로로 찌그러지거나 1, 2월만 나오던 문제를 강력한 CSS 그리드(Grid)를 주입해 **1~12월이 꽉 차는 예쁜 3x4 바둑판**으로 해결했습니다.
    
- **정상적인 월 이동 로직:** 월 선택창에서 특정 월을 클릭하면, 정상적으로 해당 월 달력으로 이동하도록 수정했습니다.
    
- **무한 줌아웃 방지:** 연도 ➡️ 10년 ➡️ 100년 단위로 계속 축소되는 것을 막아, 딱 '월 선택창'까지만 열리도록 제약을 걸었습니다.
    

**4. 디테일한 UI 감성 추가**

- **심플한 '오늘' 날짜 아이콘:** 텍스트로 된 오늘 버튼 대신, 비어있는 둥근 모서리 사각형(Squircle) 안에 매일 자정이 되면 자동으로 바뀌는 오늘 날짜 숫자(예: 17)가 들어가도록 미니멀하게 디자인했습니다.
    
- **둥근 카드 UI 복구:** 달력과 이력 패널이 부드러운 입체감을 가지도록 둥근 모서리와 그림자 효과(`rounded-3xl`, `rounded-t-[40px]`)를 살려냈습니다.
    
- **일요일 시작 & 텍스트 페이드아웃:** 달력이 항상 일요일부터 시작하도록 고정했고, 화면을 위아래로 스와이프할 때 달력 안의 금액 텍스트가 깜빡이며 사라지지 않고 스르륵 부드럽게 사라지도록(Fade-out) 처리했습니다.
    

**5. 핵심 버그 픽스**

- 모바일 환경에서 `+` 버튼으로 내역을 추가할 때, 모달 안에서 **수입/지출 토글이 작동하지 않던 버그**를 상태 관리 함수(`setType`)를 넘겨주어 해결했습니다.
