컴퓨터와 휴대폰에서 동시에 연동되면서 초보자가 시작하기 가장 좋은 기술 스택은 **'웹(Web)' 기반의 개발**입니다. 웹으로 만들면 PC 브라우저에서도 쓸 수 있고, 휴대폰에서도 브라우저를 통해 접속하거나 '홈 화면에 추가'하여 앱처럼 사용할 수 있기 때문입니다.

동기화(연동)와 초보자 편의성을 모두 잡을 수 있는 추천 조합을 단계별로 정리해 드립니다.

---

### **1. 추천 기술 스택: "The Web & Cloud Combo"**

초보자에게는 설정이 복잡한 자체 서버 구축보다는, 모든 것을 알아서 관리해 주는 **BaaS(Backend as a Service)** 활용을 강력히 추천합니다.

- **프론트엔드 (화면): React + Tailwind CSS**
    
    - **React:** 가장 인기 있는 라이브러리로 배우기 쉽고 커뮤니티가 큽니다.
        
    - **Tailwind CSS:** 디자인을 코드로 직접 짜지 않고, 정해진 클래스명(예: `w-1/5`, `flex`)만 입력하면 되어서 Gemini와 같은 레이아웃 비율 잡기에 최적입니다.
        
- **백엔드 & 데이터베이스 (저장 및 연동): Supabase**
    
    - **이유:** 초보자가 가장 어려워하는 '로그인 기능'과 '데이터 저장(DB)'을 클릭 몇 번으로 해결해 줍니다.
        
    - **동시 연동:** 구글 로그인을 연동하면 PC에서 입력한 데이터를 휴대폰에서 로그인했을 때 즉시 똑같이 볼 수 있습니다.
        
- **배포 (주소 만들기): Vercel**
    
    - 만든 코드를 올리면 `my-account-book.vercel.app` 같은 실제 인터넷 주소를 무료로 만들어줍니다.
        

---

### **2. 기기 간 연동을 위한 핵심 전략**

PC와 모바일에서 모두 쾌적하게 사용하려면 **'반응형 디자인(Responsive Design)'**이 필수입니다.

1. **비율 유지:** PC에서는 말씀하신 대로 2:8 비율을 유지하지만, 휴대폰(화면이 좁을 때)에서는 왼쪽 메뉴를 숨기고 '햄버거 버튼(≡)'으로 바꾸는 처리가 필요합니다.
    
2. **클라우드 DB 사용:** 데이터를 기기 자체에 저장(LocalStorage)하지 않고, 반드시 **Supabase** 같은 온라인 데이터베이스에 저장해야 합니다. 그래야 어떤 기기로 접속하든 데이터가 실시간으로 동기화됩니다.

### **3. 단계별 구축 로드맵 (Step-by-Step)**

#### **Step 1: 개발 환경 준비 (1~2일)**

- **Node.js** 설치: JavaScript 실행 환경입니다.
    
- **VS Code** 설치: 코드를 작성하는 도구입니다.
    
- 터미널에서 `npx create-react-app 내-가계부` 명령어로 기본 프로젝트를 생성합니다.
    

#### **Step 2: 기본 레이아웃 구성 (3~4일)**

- **Tailwind CSS**를 설정합니다.
    
- `flex`를 사용해 왼쪽 메뉴(Sidebar)와 오른쪽 메인(Calendar) 영역을 나눕니다.
    
    - PC: `flex-row` (가로 배치)
        
    - 모바일: `flex-col` (세로 배치) 또는 사이드바 숨김 처리.
        

#### **Step 3: Supabase 연동 (5~7일)**

- Supabase 프로젝트를 생성하고 '지출/수입' 테이블을 만듭니다.
    
- 로그인 기능을 구현합니다 (이메일 또는 구글 로그인).
    
- 이제 내가 입력한 데이터가 내 컴퓨터가 아닌 '인터넷 공간(DB)'에 저장됩니다.
    

#### **Step 4: 달력 및 모달 기능 구현 (8~14일)**

- `react-calendar`나 `FullCalendar` 같은 라이브러리를 설치해 달력을 띄웁니다.
    
- 날짜 클릭 시 팝업(Modal)이 뜨게 하고, `금액`, `내용`, `카테고리`를 입력받아 Supabase로 보냅니다.
    

#### **Step 5: 배포 및 모바일 확인 (마지막)**

- **Vercel**에 프로젝트를 연결하여 배포합니다.
    
- 생성된 URL 주소를 휴대폰 브라우저(Chrome, Safari)에서 접속합니다.
    
- **'홈 화면에 추가'** 버튼을 눌러 아이콘을 만들면 앱처럼 쓸 수 있습니다.
