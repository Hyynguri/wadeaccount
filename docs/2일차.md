가계부 프로젝트 2일 차 개발을 성공적으로 마치셨습니다! 오늘은 단순히 화면을 구성하는 것을 넘어, **데이터를 실제로 다루고 브라우저에 영구적으로 저장하는 핵심 로직**을 완성했습니다.

오늘 구현한 내용과 방법은 다음과 같습니다.

---

### **📝 가계부 프로젝트 개발 일지 (2일 차)**

#### **1. 데이터 상태 관리 및 저장 (Array & State)**

- **구현 내용:** 모달창에서 입력한 내역을 임시 알림으로 끝내지 않고, 실제 `transactions`라는 배열 상태(State)에 차곡차곡 쌓이도록 만들었습니다.
    
- **구현 방법:** `useState`를 사용해 전체 내역을 관리하는 바구니를 만들고, '저장하기' 버튼을 누를 때마다 새로운 내역 객체(날짜, 금액, 타입, 카테고리 등)가 기존 배열에 추가되도록 로직을 작성했습니다.
    

#### **2. 달력 내역 렌더링 (Tile Content)**

- **구현 내용:** 입력한 수입/지출 내역을 달력의 각 날짜 칸(바둑판) 안에 직접 그려 넣었습니다.
    
- **구현 방법:** `react-calendar`의 `tileContent` 속성을 활용했습니다. 해당 날짜에 데이터가 있으면 달력 칸 안에 빨간색 수입(+)과 **파란색 지출(-)** 텍스트가 나타나도록 조건부 스타일링을 적용했습니다.
    

#### **3. 로컬 스토리지(LocalStorage) 연동**

- **구현 내용:** 브라우저를 새로고침하거나 창을 닫았다가 다시 열어도 입력한 가계부 데이터가 그대로 유지되게 만들었습니다.
    
- **구현 방법:** `useEffect` 훅을 사용했습니다. 내역이 추가될 때마다 브라우저의 저장소인 `LocalStorage`에 자동으로 백업하고, 앱이 처음 실행될 때 저장된 데이터를 다시 불러와 초기 상태값으로 세팅했습니다.
    

#### **4. Git 설치 및 버전 관리 시스템 구축**

- **구현 내용:** 프로젝트의 변경 사항을 기록하고, 실수가 생겼을 때 이전 상태로 되돌릴 수 있는 '타임머신' 환경을 만들었습니다.
    
- **구현 방법:** 리눅스(WSL)에 `Git`을 설치하고 프로젝트 폴더를 저장소로 초기화했습니다. `git add`와 `git commit` 명령어를 통해 오늘까지의 작업 내용을 로컬 시스템에 영구 저장했습니다.
    

#### **5. GitHub 연동 및 인증 에러 해결**

- **구현 내용:** 내 컴퓨터뿐만 아니라 온라인(GitHub)에도 코드를 안전하게 백업했습니다.
    
- **트러블슈팅:** `git push` 과정에서 발생한 패스워드 인증 에러를 **개인 접근 토큰(PAT)** 생성과 등록을 통해 해결했습니다. 이제 온라인 저장소를 통해 어디서든 본인의 코드를 확인하고 관리할 수 있게 되었습니다.

**오늘의 요약:** 이제 이 가계부는 **"실제로 데이터를 입력하고, 그 데이터를 잃어버리지 않고 계속 관리할 수 있는"** 진짜 프로그램의 기반을 완벽히 갖추었습니다.
